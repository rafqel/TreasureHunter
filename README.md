## 📖 About

**Treasure Hunter** is a 2D action-collector game developed with Python and Pygame. 

It was developed as a semester project for a programming course, with a strong focus on clean architecture, modular code, and object-oriented programming principles. The player must navigate the map, collect treasures, and survive the challenges of the environment.

---

## ✨ Features

- 🎮 **Classic 2D Gameplay:** Smooth and responsive controls.
- 💎 **Collector Mechanics:** Objective-based gameplay focused on gathering treasures.
- 🖥️ **Custom UI:** Intuitive game menu and HUD (Heads-Up Display).
- 🧩 **Modular Code:** Built with clean code practices to facilitate maintenance and future expansions.

---

## 🛠️ Technologies

- **Python 3** – Core programming language.
- **Pygame** – Cross-platform set of Python modules designed for writing video games.

---

## ⚙️ How to Run

### Prerequisites
You need to have **Python 3** installed on your machine. You can download it at [python.org](https://www.python.org/).

### Step-by-Step
1. Clone this repository:
   `git clone https://github.com/rafqel/treasure-hunter.git`

2. Navigate to the project folder:
   `cd treasure-hunter`

3. Install the Pygame dependency:
   `pip install pygame`

4. Run the game:
   `python main.py`
   *(Note: If your main file has a different name, replace `main.py` with the correct filename).*
